# KubeRay artwork

KubeRay beaver logos are available in horizontal, stacked, and icon layouts. Each layout includes beaver color, beaver black, and beaver white versions in PNG and SVG formats (18 assets).

The artwork uses transparent backgrounds. The beaver black and beaver white variants use a single visible color, with transparent negative space for details. Icon canvases are square. Excess transparent margins are trimmed without changing the supplied illustration or outlined wordmarks.
