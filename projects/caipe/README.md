# CAIPE artwork reference

[CAIPE](https://caipe.io/) is a CNCF Sandbox project. This directory contains the original artwork reference for design assistance during [project onboarding](https://github.com/cncf/sandbox/issues/549).

- [Original SVG](source/caipe_11.svg): supplied unchanged by a CAIPE maintainer.
- The SVG embeds a PNG illustration; the mascot is not yet represented as editable vector paths.
- The requested work is a faithful vector redraw and the standard horizontal, stacked, and icon layouts in color, black, and white, with SVG and PNG exports.
- Preserve the existing mascot identity and blue/teal palette while making the artwork suitable for small icons and monochrome use.

This is source reference material for an incomplete draft, rather than a finished logo package. The standard variants and the repository's example galleries still need to be completed.

CNCF lists [design and logo assistance](https://contribute.cncf.io/resources/services/) as a service requested through the [CNCF Service Desk](https://servicedesk.cncf.io/).
